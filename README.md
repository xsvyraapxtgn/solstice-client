## Overview

Solstice Client is a feature-rich client for Minecraft Bedrock Edition 26.60 (Wilderness Bound) on Windows, delivering FPS optimizations, visual enhancements, and a hotkey-toggled module suite built for PvP and survival. It maintains compatibility with the latest Bedrock release through rapid update cycles and offers a clean in-game GUI for enabling and tuning individual modules without restarting the game. Whether you play on competitive servers or solo survival worlds, Solstice Client elevates the Bedrock experience beyond vanilla limits.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Solstice Client** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Bedrock 26.60 Support** | Fully compatible with Minecraft Bedrock Edition 26.60 Wilderness Bound |
| **FPS Optimization** | Chunk-loading and render-pipeline improvements over vanilla Bedrock |
| **PvP Modules** | Hit registration display, reach indicator, and CPS counter toggles |
